How generation works

The Quality Engine ranks competing plans before anything is compiled.

Generation is the expensive step and it happens once, for the plan that won. Rendering is deterministic: nothing unregistered ever executes.

  1. IntentWhat the user is trying to do, in their words.
  2. ContextApp state, data, permissions, and what happened last time.
  3. CandidatesSeveral competing UI plans — plus chat and a static screen as baselines.
  4. Quality EngineScored on task fit, clarity, accessibility and cost. One plan wins.
  5. CompileGrounded against your registry. Invalid nodes are stripped, never guessed.
  6. RenderStreams component by component in your design system.
  7. OutcomeCompletion, correction or abandonment feeds the next decision.
The SDK

One import. An intent in, a live interface out.

Streaming, the action loop, and loading, empty and error states are handled. The surface inherits your colour and type; tune the rest with tokens.

Render one intent

Drop it where a chart or a form would have gone. It decides which one the task needs.

import { Ovxa } from "@ovxa/sdk";
import "@ovxa/sdk/styles.css";

<Ovxa
  intent="Compare Q2 revenue against Q1"
  data={revenue}
/>

Let the user ask

A search box for interfaces. Suggestions before they type, the answer underneath when they do.

import { OvxaSearch } from "@ovxa/sdk";

<OvxaSearch
  data={workspace}
  theme={{ radius: "var(--radius)" }}
  onIntent={(intent) => track(intent)}
/>

Guarantees

Fail closed. Degrade gracefully.

Generated output is data, never code. Everything a model writes is checked against your registry as it streams.

Unregistered components never render

Component types, prop shapes and action ids are allowlists. A node that cannot resolve is stripped; a surface that cannot be grounded becomes a simpler one, never a blank screen.

Patch, don't regenerate

Interactions return a patch addressed by node id. Selections, form values, focus and scroll survive every turn — and most actions never reach a model at all.

It inherits your design system

The surface takes your colour and font. Every other visual is a token. Map your components when you are ready; anything unmapped still shows its data.

Latency is a feature

The shell streams as soon as a plan wins — before generation starts. Data is bound by reference, so the model never transcribes a record: cost tracks components, not rows.
